# 資料方法與來源

## 範圍

- 市場：台灣線上零售通路，幣別 NTD。
- 型號：RTX 5090、5080、5070 Ti、5070、5060 Ti 16GB、5060 Ti 8GB、5060、5050。
- 頻率：2026-04 至 2026-09，每月一筆每型號。
- 指標：同月納入樣本的價格中位數，不代表 NVIDIA 建議售價、成交價或所有 AIB 品牌平均。

## 固定蒐集規則

1. 每月月中（建議 10-20 日）擷取每個型號至少 5 個「可下單、全新、獨立顯示卡」的標價；記錄網址、品牌/型號、價格、時間。
2. 排除二手、預購、整機綁售、主機板綁售、無庫存、點數回饋、信用卡折扣、開箱品與無法辨識顯存版本的列項。
3. 同一 AIB 型號在同一通路只保留一次；不要讓同一商品重複進入樣本。
4. 將價格由低至高排序：奇數樣本取正中間；偶數樣本取中間兩筆平均後四捨五入至整數。
5. 在 CSV 寫入中位數、實際樣本數與使用通路集合；蒐集明細只留在你的工作表，不上傳到這個公開 repository。

## 本專案 CSV 的定位

`rtx50_tw_monthly_median.csv` 是可直接驅動圖表的**月中位數彙整檔**。它不包含通路原始 JSON、商品頁 HTML、會員資料或逐筆商品列項。

其中現有 2026-04 至 2026-09 數值作為專案可執行的初始靜態資料集；公開發表前，應依上方規則用你保留的月中紀錄逐列覆核與取代。歷史商品頁可能已下架或被通路改價，無法單靠今天的商品頁反向證明某月的價格。
